SN Generator

ตั้งได้หลายชุดพร้อมกัน แต่ละชุดมี prefix / ช่วงเลข / จำนวนหลัก / step เป็นของตัวเอง กดสร้างรวมทีเดียว copy หรือโหลดไฟล์ได้ครบทุกชุด

คู่มือ — โหมดสร้างเลขรัน (สร้างตามช่วง)

  • แต่ละ ชุด สร้างเลขตาม START → END แล้วรวมทุกชุดในลิสต์เดียวตอนกด "สร้างรายการทั้งหมด" — เพิ่มได้หลายชุดด้วยปุ่ม + เพิ่มชุด SN
  • PREFIX = ข้อความนำหน้าตัวเลข · STEP = กระโดดทีละ (เช่น 2 = ข้ามเลขคี่) · DIGITS = จำนวนหลัก (ระบบเติมเลข 0 นำหน้าให้เท่ากัน เช่น 5 หลัก → 00102)
  • วาง START มากกว่า END ได้ → รันเลขไล่ลงมา
  • วาง SN ตัวอย่าง 2 บรรทัดในกล่อง "วาง SN ตัวอย่าง" แล้วกด ตรวจจับอัตโนมัติ → ระบบเดา prefix / ช่วง / หลัก ให้เอง
  • กด ตั้งเป็นค่าเริ่มต้น = เก็บชุดนี้เป็นค่าพรีเซ็ตของชุดใหม่ในรอบถัดไป
  • ถ้ามีรหัสซ้ำกันระหว่างชุด → ใช้ แสดงเฉพาะที่ชนกัน ดูได้ และ แก้อัตโนมัติ จะเลื่อน range ให้ไม่ชนกัน

คู่มือ — รันเลขจากตัวอย่าง (อยู่ในแท็บที่ 2)

  • วาง SN ทีละคู่ — ตัวที่ 1 = จุดเริ่ม, ตัวที่ 2 = จุดจบของช่วง → ระบบเติมเลขที่ขาดหายไปของคู่นั้นให้ครบ (step 1)
  • วางคู่ถัดไปต่อได้เรื่อย ๆ คั่นด้วย ช่องว่าง / คอมม่า / แท็บ / ขึ้นบรรทัดใหม่ เช่น วาง S8N2606A00145 S8N2606A00153 → ได้ 00145...00153
  • ใช้ dash ระหว่างคู่ก็ได้ เช่น S8N2606A00145-S8N2606A00153
  • ถ้าเหลือตัวเลขคี่ (จับคู่ไม่ลงตัว) → ใส่เป็นรายการเดี่ยวในผลลัพธ์
  • SN ที่ prefix ต่างกันจะไม่ถูกจับคู่กัน — แต่ละตัวกลายเป็นรายการเดี่ยว
  • กด สร้างรายการทั้งหมด ครั้งเดียว ระบบรวมผลจากทั้ง 2 แท็บให้เลย

คู่มือ — โหมดนำเข้า

  • วาง SN ที่มีอยู่แล้วลงกล่อง คั่นด้วย คอมม่า / ช่องว่าง / แท็บ / ขึ้นบรรทัดใหม่ ได้หมด — ระบบแปลงเป็นรายการคอลัมน์และรวมเข้าผลลัพธ์
  • Prefix / Suffix จะเติมข้อความหน้าและท้ายให้ทุกตัวที่นำเข้า เช่น วาง 0012 + prefix SN- → SN-0012
  • เลข 0 นำหน้าถูกเก็บไว้ตามเดิม — ตอนเปิด CSV/Excel ระบบครอบเป็นข้อความเพื่อไม่ให้ 00 หาย
  • เปิดโหมดนี้เฉพาะตอนอยากรวมรหัสที่ไม่ได้สร้างเอง (ถ้าไม่ใช้ก็ปิดได้)

คู่มือ — โหมดแปลงตัวพิมพ์

  • วาง text ลงกล่อง คั่นด้วย คอมม่า / ช่องว่าง / แท็บ / ขึ้นบรรทัดใหม่ ได้หมด — เช่น s8n2606a00102
  • เลือกทิศทาง พิมพ์ใหญ่ (UPPER) หรือ พิมพ์เล็ก (lower) แล้วกด "สร้างรายการทั้งหมด" ระบบแปลงให้ทุกตัวแล้วรวมเข้าผลลัพธ์
  • ภาษาไทยไม่มีตัวพิมพ์เล็ก/ใหญ่ ระบบจะคงข้อความเดิมไว้ให้
  • เปิดโหมดนี้เฉพาะตอนอยากแปลง (ถ้าไม่ใช้ก็ปิดได้)
